# Reworn frontend

The React/Vite/Tailwind client for the Reworn secondhand clothing marketplace.

## Local development

```bash
cp .env.example .env.local
npm install
npm run dev
```

Set `VITE_API_URL` in `.env.local` if the API is not running at `http://localhost:4000`.

## Commands

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

See the repository-level `README.md` for the complete backend, environment, API, and Vercel setup.
